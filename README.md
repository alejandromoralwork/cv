# Alejandro Moral Aranda CV

This repository contains the CV website and its role-specific pages. Shared styles, scripts, images, and documents live in `assets/`; the root `index.html` links to the CV versions.

## Static Finance and Data Analyst CV

Open [`FinanceDataAnalyst/`](./FinanceDataAnalyst/) for the general Finance and Data Analyst CV. Its profile, work history, education, skills, languages, and eight projects are embedded in the page and use local images, so the CV itself does not depend on Firebase or database availability.

The page keeps the CV/Projects navigation, standard and ATS-friendly PDF downloads (with optional project pages), and browser printing.

## Other pages

The other role-specific CV pages and the admin tools remain available. Some of those pages use Firebase; the Finance and Data Analyst page does not.

The site can be served from the repository root with GitHub Pages. No build step is required.
